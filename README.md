# ARGUS

PC 브라우저에서 플레이하는 1–4인 협동 PvE. C# 서버가 이동·근접 RPS·피해·마나·시야·임무를 계산하고 TypeScript/PixiJS 클라이언트가 입력과 화면을 담당한다.

## 실행

.NET 10 SDK와 Node.js 22.12 이상이 필요하다. Linux/WSL에서도 실행할 수 있다. 저장소 루트에서:

```bash
npm --prefix client ci
npm --prefix client run build
dotnet run --project server/Argus.Server --urls http://127.0.0.1:5077
```

브라우저로 <http://localhost:5077>에 접속한다. 호출명과 자유 슬롯을 고르고 **새 작전 시작 → 캠프 선택 → 5초 후 투입**을 누른다. **투입 마나는 0이므로 캠프 오른쪽 아래 보급 상자에 접근해 충전**한다.

친구는 같은 서버 주소에서 6자리 방 코드를 입력한다. 다른 PC와 시험하려면 서버를 `--urls http://0.0.0.0:5077`로 실행하고 해당 PC에서 접속 가능한 서버 주소를 사용한다. 방 코드만으로 다른 PC의 localhost에 연결되지는 않는다.

클라이언트 개발 중에는 서버를 5077로 켠 뒤 별도 터미널에서 `npm --prefix client run dev`를 실행하고 <http://localhost:5173>을 연다. Vite가 API와 WebSocket을 서버로 전달한다. 서버 시작점은 `server/Argus.Server/Program.cs`의 `Main`이다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동. 기술 사용 중에도 가능 |
| 마우스 | 방향 지정 |
| 좌클릭 / 1 | 슬롯 1: 근접 타격 |
| 우클릭 / 2 | 슬롯 2: 받아치기 |
| Space / 3 | 슬롯 3: 근거리 잡기 |
| Q / 4 | 슬롯 4: 선택한 추가 기본기 |
| M | 전체 지도 |
| 보급 상자에 접근 | 체력·마나 보충, 부목표 회수 |

입력을 유지하면 동작이 끝난 뒤 반복한다. 세 기본기 모두 마나 1을 소비하며 빗나가도 환불하지 않는다. 자연 회복은 없다. 자유 슬롯에는 기본기를 중복 장착하며 기본기는 한 번에 하나씩 사용한다. 슬롯 밖 사격과 재장전은 없다.

## 전투와 임무

- **타격은 잡기를, 잡기는 방어를, 방어는 타격을 이긴다.** 적의 예고 이름·색·방향·진행률을 보고 대응한다.
- 첫 맵에는 1티어 일반 병사만 등장한다. 선딜은 타격 1.7초, 방어·잡기 1.9초다. 받아치기는 방어가 0.55초이므로 적 타격 예고가 끝날 무렵 사용한다.
- 일반 적에게 이기면 피해 없이 처치, 비기면 서로 피해 1, 지면 나만 피해 1이다. 무행동인 적에게는 일반 피해 1이다.
- 받아치기는 전방 120°를 잠깐 방어한 뒤 일반 반격한다. 빈 방어 뒤에도 반격하며, 상성 패배 시에는 취소한다. 잡기는 한 동작 동안 한 명을 대상으로 판정을 유지한다.
- 이후 작전용으로 남겨둔 큰 엘리트의 **Ⅱ** 예고는 유효한 대응 두 개가 필요하다. 아군과 겹쳐 함께 대응할 수 있다. 완전 파훼는 엘리트를 처치하고 같은 공격 범위의 다른 동료까지 보호한다. 엘리트의 Ⅰ 행동도 완전히 파훼하면 처치한다.
- 분쇄자는 타격 Ⅱ, 철위병은 타격·방어 Ⅱ를 사용한다. 현재 첫 맵에는 두 종류 모두 등장하지 않는다. 엘리트 출현과 적 선딜 배율은 `Rules.cs`에서 조정한다.
- 아군끼리는 겹치며 피해를 주지 않는다. 적과 플레이어, 적끼리는 몸으로 길을 막는다.
- 시설 3곳을 타격이나 반격으로 부순 뒤 남쪽 탈출 구역에 한 명 이상이 20초 머물면 성공한다. 부목표 보급품 2개는 선택 사항이다. 벽도 타격으로 파괴할 수 있다.
- 첫 투입·난입·증원 모두 위치 확정 후 5초. 미선택이면 계속 대기하며 기본 무적은 없다. 살아 있는 동료가 있으면 무제한 증원 가능, 전원 사망하면 실패, 솔로는 첫 사망에 실패한다.
- 임무 시작부터 10분마다 캠프를 포함한 모든 생존자에게 2 → 4 → 8… 피해를 준다. 현재 체력 6·마나 24와 함께 시험 수치다.

합의한 판정과 조정 가능한 수치는 [전투 명세](docs/combat.md), 전체 방향은 [요구사항](docs/requirements.md)에 기록했다. 원거리 기술·마력탄·광선·이전 총기·수류탄·터렛은 현재 기본기 출시 범위에 없다.

## 접속과 서버 권위

로그인 없는 게스트이며 방 코드로 진행 중 난입할 수 있다. 각 탭은 비밀 복구 토큰을 `sessionStorage`에 저장한다. 같은 탭 새로고침은 기존 상태로 복귀한다. 새 탭은 별도 게스트로 열 수 있으며, 탭 복제는 브라우저에 따라 같은 토큰을 복사할 수 있다.

끊긴 대원은 입력이 중단된 채 피격 가능한 상태로 120초 남는다. 재접속은 체력·마나·장비·기술·증원 시간을 유지한다. 같은 토큰의 새 연결은 이전 연결을 교체한다. 나가기는 복구 정보를 지우며 이전 자리는 유예 후 해제된다.

서버는 캠프와 생존 팀원의 시야를 합쳐 숨겨진 적의 위치·예고·효과를 직렬화 전에 제외한다. 맵·벽·시설·보급 진행은 공개 정보다. 서드파티 클라이언트용 [protocol v2](docs/protocol.md)를 제공한다. 이전 사격용 v1과 호환되지 않으므로 서버와 브라우저 빌드를 함께 갱신한다.

## 수정할 곳

| 파일 | 역할 |
| --- | --- |
| `Game/Rules.cs` | 기본기 수치, 엘리트 출현 허용, 적 선딜 배율 |
| `Game/SkillDefinition.cs` | 상성, 적별 기술 티어·부분 대응 효과 |
| `Game/Model.cs` | 대원·적·기술 인스턴스의 상태 |
| `Game/Match.cs` | 입력·마나·보급·증원·임무 진행 순서 |
| `Game/Match.Combat.cs` | 접촉·상성·협동 파훼·후속 공격 |
| `Game/Match.Movement.cs` | 몸 충돌·AI 이동과 예고 시작 |
| `Game/BattleMap.cs` | 벽 충돌·정확한 타일 사선 검사·벽 파괴 |
| `Game/Snapshot.cs`, `Game/SnapshotMessage.cs` | 공개 상태와 통신 데이터 구조 |
| `Networking/RoomHost.cs`, `Program.cs` | 방·복구 토큰·실행 루프·접속과 입력 경로 |
| `client/src/main.ts` | 로비·네 슬롯 조작·HUD·재접속 |
| `client/src/world.ts` | 단순한 도형, 예고, 보간·이동 예측 |

서버 파일 경로는 `server/Argus.Server/` 기준이다. C#은 [작성 규칙](AGENTS.md)에 따라 명시적 타입과 일반 생성자, for/foreach와 if/else로 작성한다.

## 검사

```bash
dotnet run --project tests/Argus.Server.Tests
npm --prefix client run build
```

서버를 실행한 뒤 브라우저 검사:

```bash
cd client
npx playwright install --with-deps chromium
npm run test:e2e
```

다른 포트에는 `ARGUS_URL`을 설정한다. 검증 결과와 범위는 [검증 기록](docs/verification.md)에 있다.

## 운영 범위

메모리 기반 단일 서버다. DB·영구 저장·성장·보상은 없으며 서버 재시작 시 방과 토큰이 사라진다. 시뮬레이션 목표 30Hz, 상태 전송 약 10Hz. 서버 처리가 늦어지면 작은 단계로 나눠 진행한다. 브라우저는 이동을 예측하고 서버 위치로 보정한다. 하드웨어 WebGL이 없으면 PixiJS Canvas 렌더러를 사용한다.

방 32개·방당 적 60마리는 설정 상한이며 부하 보장값이 아니다. 사운드와 정교한 밸런스는 아직 없다. Docker 설정은 로컬 5077을 노출한다. GKE 확장 전 방 배정·연결 라우팅·종료 절차·관측·부하 검증이 필요하다. 현재 여러 복제본 사이에 방 상태를 공유하지 않으므로 단일 인스턴스로 운영한다.
